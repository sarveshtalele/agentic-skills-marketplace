## Project Overview

**Test Automation Skill Suite** — complete end-to-end testing, BDD specification, synthetic test data generation, and Playwright execution framework for AI agents.

- **5 Integrated Testing Skills**:
  1. `test-design-generator`: Comprehensive boundary value and decision matrix generator.
  2. `test-data-generator`: Realistic mock datasets (JSON, CSV, SQL) with relational referential integrity.
  3. `gherkin-generator`: Business-readable Given-When-Then BDD feature specifications.
  4. `playwright-test-generator`: Automated generation of resilient Playwright E2E browser tests.
  5. `playwright-test-executor`: Deterministic execution and trace failure triage for Playwright suites.

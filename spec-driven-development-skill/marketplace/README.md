# Spec-Driven Development (SDD) Skill Suite

A formal 4-phase development framework ensuring zero architectural drift between requirements, design, implementation, and verification.

| Phase | Skill | Primary Deliverable |
| :--- | :--- | :--- |
| **Phase 1: Specify** | `sdd-specify` | `spec.md` (Formal requirements & interface contracts) |
| **Phase 2: Plan** | `sdd-plan` | `plan.md` (Implementation strategy & file delta map) |
| **Phase 3: Implement** | `sdd-implement` | Source code changes + unit tests |
| **Phase 4: Verify** | `sdd-verify` | `verification_report.md` (100% compliance audit) |

---

## 🚀 Quick Installation

```bash
# Claude Code:
cp -r skill/* ~/.claude/skills/

# Cursor:
cp -r skill/* .cursor/skills/
```

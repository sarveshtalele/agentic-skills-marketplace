## Project Overview

**Spec-Driven Development (SDD) Skill Suite** — formal 4-stage lifecycle for deterministic feature development based on contract specifications:

- **4 Core SDLC Skills**:
  1. `sdd-specify`: Formal functional requirements & API contract specifications.
  2. `sdd-plan`: Step-by-step implementation and risk assessment architecture.
  3. `sdd-implement`: Strict test-driven coding adhering strictly to the contract.
  4. `sdd-verify`: Automated contract verification and regression auditing.
